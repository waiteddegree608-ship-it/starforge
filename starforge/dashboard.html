以下为证据指标，不给模型主观打分包装成客观分数。

  • 需求：至少 2 个真实来源，能说明同一具体问题。
  • 可用性：有真实输入、帮助、演示与边界测试；测试数量不代表已通过。
  • 质量：独立审查通过，随后 GitHub CI 通过。
  • 文档：英文和中文使用说明、例子与限制。
  • 增长：Star、Fork、开放 Issue，以及逐次变化。
  • 性价比：日费用、请求数、审查转化率与发布数量。
